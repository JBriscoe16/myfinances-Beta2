
# MyFinances TTU — Beta 2

## ENGR 1340 | Project 2

### Project Overview

MyFinances TTU is a budgeting website designed to help Texas Tech students manage their expenses, plan monthly budgets, and track their savings.

Our team, Beta 2, is developing the website using HTML and CSS.

### Project Proposal

| Item | Description |
|---|---|
| App Name | MyFinances TTU |
| Team | Beta 2 |
| App Type | Personal Finance / Budget Tracker |
| Target Users | Texas Tech students |
| Problem | Students need an easier way to manage their expenses and savings. |
| Solution | A simple website for tracking budgets, spending, and savings goals. |
